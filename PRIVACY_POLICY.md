# Privacy Policy

Fxck Social Media stores its data locally in Chrome extension storage.

What is stored:

- Selected domains
- Timer defaults
- Active timer state
- Manual blocking state
- Dynamic-rule bookkeeping
- Last displayed quote image ID

What is not collected by default:

- Browsing history
- Page content
- Analytics events
- Remote telemetry
- User account data

Quote assets are bundled locally with the extension build. The extension does not fetch remote quote images at runtime.

Host permissions are requested only for domains the user selects. Those permissions are used only to apply Chrome Declarative Net Request blocking rules for those domains.
